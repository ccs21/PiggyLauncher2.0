# Piggy Launcher 2.0

**PC 게임과 에뮬레이터 게임을 한곳에서 관리하는 Windows 게임 런처**

UMPC와 게임패드 사용 환경을 고려해 개발하고 있습니다.

> **현재 개발 중입니다. 정식 설치 파일은 아직 배포하지 않습니다.**
> 이 저장소는 Piggy Launcher 2.0의 공식 배포 및 업데이트 안내 공간입니다.

[다운로드 / 업데이트](https://github.com/ccs21/PiggyLauncher2.0/releases) · [버그 제보](https://kwtech.co.kr:5443/bug-report) · [Piggy Launcher Classic](https://github.com/ccs21/PiggyLauncher)

## 2.0에서 준비하고 있는 기능

- Steam · Epic Games · GOG · STOVE 설치 게임 자동 등록과 수동 등록
- 에뮬레이터 및 ROM 라이브러리 관리, `gamelist.xml` 지원
- 게임패드에 맞춘 카드 / 그리드 탐색과 게임 상세 화면
- 사용자 테마와 테마 메이커
- 한국어 · 영어 · 일본어 지원
- 광고 없는 런처

개발 중인 기능을 포함하며, 최종 지원 범위와 사용 방법은 정식 출시 시 안내합니다.

## 설치 및 업데이트

정식 출시 후 **[Releases](https://github.com/ccs21/PiggyLauncher2.0/releases)**에서 설치 파일을 제공합니다.

신규 설치와 업데이트에 **동일한 통합 인스톨러**를 사용하는 방식으로 준비하고 있습니다. 설치용 ZIP과 업데이트 전용 파일을 구분해서 받을 필요가 없도록 할 예정입니다.

- **처음 사용하는 경우:** 설치 경로를 선택해 설치합니다.
- **2.0을 사용 중인 경우:** 런처의 업데이트 메뉴에서 새 버전을 확인하고 진행합니다.
- **Classic을 사용 중인 경우:** 기존 설정과 게임 목록을 이전하는 절차를 제공할 예정입니다. 구체적인 이전 방법은 출시 시 안내합니다.

상세 사용 설명서는 기능 구현을 마친 뒤 런처에 내장할 예정입니다.
