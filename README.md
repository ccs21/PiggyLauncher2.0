# Piggy Launcher 2

**PC 게임과 에뮬레이터 라이브러리를 한곳에서 관리하는 Windows 게임 런처**

UMPC와 게임패드 사용 환경을 고려한 Piggy Launcher 2의 공식 배포 저장소입니다. 현재 배포 버전은 아래 최신 설치 파일 링크에서 확인할 수 있습니다.

[최신 설치 파일](https://github.com/ccs21/PiggyLauncher2.0/releases/latest) · [업데이트 이력](https://piggylauncher2.dothome.co.kr/updates.html) · [사용 설명서](https://piggylauncher2.dothome.co.kr/manual.html) · [버그 제보](https://kwtech.co.kr:5443/bug-report)

## 주요 기능

- Steam, Epic Games, GOG, STOVE 및 직접 설치한 PC 게임을 라이브러리에서 관리
- 에뮬레이터 ROM 목록과 `gamelist.xml` 지원
- UMPC와 게임패드에 맞춘 탐색, 게임 상세 정보 및 실행 설정
- 기본 제공 테마, 사용자 테마 및 ThemeMaker
- 한국어, 영어, 일본어 지원

## 설치 및 업데이트

Windows 64비트에서 [최신 릴리즈](https://github.com/ccs21/PiggyLauncher2.0/releases/latest)의 `PiggyLauncher-Setup-x64.exe`를 실행하세요. 신규 설치와 업데이트에 같은 설치 파일을 사용합니다. 설치 파일의 SHA-256 값은 릴리즈에 함께 게시된 `.sha256` 파일에서 확인할 수 있습니다.

설치된 Piggy Launcher 2에서는 업데이트 메뉴로 새 버전을 확인하고 설치할 수 있습니다. 이미 표시된 버전과 공개 버전이 같다면 자동 업데이트가 제공되지 않으므로, 해당 릴리즈의 설치 파일을 직접 실행하세요.

Classic에서 업그레이드할 때는 기존 게임 라이브러리와 설정을 이전합니다. ROM 폴더에 `gamelist.xml`이 이미 있다면, 기존 XML을 검증해 사용하거나 백업 후 Classic JSON 목록을 새 XML로 변환할지 선택할 수 있습니다. 설치 대상 밖의 게임 및 ROM 파일은 이동하지 않습니다. 중요한 개인 데이터는 업데이트 전에 별도로 백업해 두는 것을 권장합니다.

자세한 변경 사항은 [업데이트 이력](https://piggylauncher2.dothome.co.kr/updates.html)과 각 [릴리즈 노트](https://github.com/ccs21/PiggyLauncher2.0/releases)를 확인하세요.

## English

**Piggy Launcher 2** is a Windows game launcher for PC games and emulator libraries, designed with handheld gaming PCs and gamepads in mind. Check the latest release link below for the current version.

Manage Steam, Epic Games, GOG, STOVE, manually installed PC games, emulator ROM lists, and `gamelist.xml` in one library. Built-in and user themes, ThemeMaker, and Korean, English, and Japanese interfaces are available.

Download `PiggyLauncher-Setup-x64.exe` from the [latest release](https://github.com/ccs21/PiggyLauncher2.0/releases/latest) for 64-bit Windows. The same installer handles new installations and updates. The launcher can check for newer releases; if your installed version already matches the published version, run the installer manually. A SHA-256 checksum is provided with the release.

When upgrading from Classic, the installer migrates the library and settings. If a ROM folder already contains `gamelist.xml`, you can validate and keep it, or back it up and convert the Classic JSON list to a new XML file. Back up important personal data before updating.

## 日本語

**Piggy Launcher 2**は、PCゲームとエミュレーターのライブラリーをまとめて管理するWindows向けゲームランチャーです。UMPCとゲームパッドでの利用を想定しています。現在のバージョンは下記の最新リリースから確認できます。

Steam・Epic Games・GOG・STOVE・手動登録したPCゲーム、エミュレーターのROM一覧と`gamelist.xml`に対応します。標準テーマ、ユーザーテーマ、ThemeMakerを利用でき、韓国語・英語・日本語に対応しています。

Windows 64ビットでは[最新リリース](https://github.com/ccs21/PiggyLauncher2.0/releases/latest)から`PiggyLauncher-Setup-x64.exe`をダウンロードしてください。新規インストールと更新には同じインストーラーを使います。ランチャーから新しいバージョンを確認できますが、表示上のバージョンが公開版と同じ場合はインストーラーを直接実行してください。SHA-256チェックサムも同じリリースに掲載しています。

Classicから更新する場合はライブラリーと設定を移行します。ROMフォルダーに既存の`gamelist.xml`がある場合、検証してそのまま使うか、バックアップしてClassicのJSON一覧を新しいXMLに変換するか選べます。更新前に重要な個人データを別途バックアップしてください。
